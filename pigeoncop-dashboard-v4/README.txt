PigeonCop Dashboard V4
======================

Changes:
- Green-only visual theme.
- Removed left sidebar.
- Removed redundant stats row.
- Camera and compact monitoring controls are directly adjacent.
- Recent Detections and Telemetry remain on the right.
- Activity remains below the controls.
- Added extended Loud Alert and High Frequency sounds.
- Added High Frequency Pulse and a synthetic Gunshot sound.
- Existing Camera/YOLO/Test Video/uploaded-video/deterrent wiring is preserved.

Install from PigeonCop root:
  unzip ~/Downloads/pigeoncop-dashboard-v4.zip
  bash pigeoncop-dashboard-v4/install-dashboard-v4.sh
  npm run dev

Open:
  http://localhost:5173/monitor
