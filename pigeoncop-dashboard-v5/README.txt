PigeonCop Dashboard V5
=======================

Changes requested:
1. Smaller monitoring viewport so the control row is visible sooner.
2. Longer/stronger deterrent audio assets.
3. Added High Frequency Pulse + synthetic Gunshot.
4. Green-only visual treatment.
5. Removed the redundant Current Run panel.
6. Existing App / Camera / Test Video / detection pipeline is preserved.

Important:
- The audio files are synthetic browser assets.
- "Gunshot" is a synthetic sound effect, not a real recording.
- The package does not add a backend or authentication.
- The installer backs up App.jsx and existing dashboard/audio files.

Install from the PigeonCop project root:
  unzip ~/Downloads/pigeoncop-dashboard-v5.zip
  bash pigeoncop-dashboard-v5/install-dashboard-v5.sh
  npm run dev

Open:
  http://localhost:5173/monitor
