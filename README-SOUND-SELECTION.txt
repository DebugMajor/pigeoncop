PigeonCop - Sound Selection UI

This package updates the sound-selection feature and UI.

It includes:
- src/App.jsx
- src/components/Camera.jsx
- src/components/ControlPanel.jsx
- src/sound-selection.css
- public/sounds/deterrent-loud-alert.wav
- public/sounds/deterrent-high-frequency.wav

The existing public/sounds/motion-feedback-soothing-rock.wav is intentionally not included.
Keep your existing file.

Install from the PigeonCop project root in Git Bash:

unzip -o "C:/Users/shash/Downloads/pigeoncop-sound-selection-ui-v2.zip"

Then run:

npm run dev

The selected sound is used by both Test Sound and automatic bird deterrence.
