PigeonCop Dashboard V8

Viewport-first desktop dashboard and Test Sound toggle.

Install from PigeonCop root:
  unzip ~/Downloads/pigeoncop-dashboard-v8.zip
  bash pigeoncop-dashboard-v8/install-dashboard-v8.sh
  npm run dev

Desktop:
  http://localhost:5173/monitor

Test Sound:
  click once = play
  click again while playing = stop + reset
