PigeonCop Sound Stop Fix V10

Fixes the actual deterrent audio owned by Camera.jsx.

Stops and resets deterrent audio when:
- Test Video is paused
- Reset Test is clicked
- Monitoring is stopped
- a different deterrent sound is selected

Install from the PigeonCop project root:
  unzip ~/Downloads/pigeoncop-sound-stop-fix-v10.zip
  bash pigeoncop-sound-stop-fix-v10/install-sound-stop-fix-v10.sh
  npm run dev
