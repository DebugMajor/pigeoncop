PigeonCop Dashboard CSS Fix V12.1

Use this if V12 installed App.jsx but V12 CSS was not copied.

Install from PigeonCop root:
  unzip ~/Downloads/pigeoncop-dashboard-css-fix-v12_1.zip
  bash pigeoncop-dashboard-css-fix-v12_1/install-dashboard-css-fix-v12_1.sh
  npm run dev

This patch does NOT replace App.jsx or Camera.jsx.
