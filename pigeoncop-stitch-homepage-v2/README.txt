PigeonCop — Stitch Homepage Integration v2

What this installs:
- Stitch-inspired PigeonCop landing page
- Detect / Deter / Protect hero
- TEST NOW flow into the existing monitoring dashboard
- How It Works, System Overview, Capabilities and Technology sections
- GitHub CTA
- Dashboard HOME button
- Responsive homepage styling

The installer preserves the existing Camera / YOLO / Test Video / deterrent logic.
It creates a timestamped backup before modifying App.jsx/App.css.

IMPORTANT:
Run the installer from the PigeonCop project root — the folder containing src/App.jsx.

Commands:
python install-stitch-homepage-v2.py
npm run dev
