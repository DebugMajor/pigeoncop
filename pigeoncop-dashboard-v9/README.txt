PigeonCop Dashboard V9

Fixes:
- Cleaner, more balanced single-screen desktop dashboard.
- Camera + controls + activity fit beside the right-side Recent Detections / Session Status.
- Desktop page scrolling disabled.
- Test Sound is a toggle.
- Test Sound stops on second click.
- Test Sound stops when Test Video is paused.
- Test Sound stops on Reset Test.

Install from the PigeonCop project root:
  unzip ~/Downloads/pigeoncop-dashboard-v9.zip
  bash pigeoncop-dashboard-v9/install-dashboard-v9.sh
  npm run dev

Open:
  http://localhost:5173/monitor
