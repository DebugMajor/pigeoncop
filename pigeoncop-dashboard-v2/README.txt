PigeonCop Dashboard V2

Implements the supplied dark monitoring-console design while preserving the existing
PigeonCop CV pipeline and control props.

Install from the PigeonCop project root:
  unzip ~/Downloads/pigeoncop-dashboard-v2.zip
  bash pigeoncop-dashboard-v2/install-dashboard-v2.sh
  npm run dev

Open:
  http://localhost:5173/monitor

A backup of src/App.jsx and src/App.css is created automatically.
