PigeonCop Homepage V5
======================

Implements the supplied Stitch-inspired design in React/CSS.

Changes:
- Cleaner header and navigation.
- Uses only /logo-wordmark.png so the bird mark does not overlap with the wordmark.
- Larger hero typography.
- Real pigeon photograph inside the monitoring preview.
- Detection box, confidence label, motion indicator and telemetry.
- Right-side live stats + radar-style visual.
- Lower technical proof strip.
- Workflow, technology and CTA sections.
- Keeps the existing dashboard and /monitor route untouched.

The pigeon photo is loaded from an Unsplash image URL:
https://unsplash.com/es/fotos/paloma-gris-en-el-tejado-9LUO11P5Ez8

Install from the PigeonCop root:
  unzip ~/Downloads/pigeoncop-homepage-v5.zip
  bash pigeoncop-homepage-v5/install-homepage-v5.sh
  npm run dev

Open:
  http://localhost:5173/
